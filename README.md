Student Directory Viewer

Problem Description

This project is a Student Directory Viewer developed
using React Native and Expo.

It allows an academic adviser to browse students,
search for students by name, and flag students
who need academic advising.

Components Used

StudentCard
- Displays the student's profile picture.
- Displays the student's name and year level.
- Contains the Flag for Advising button.

StudentDirectory
- Holds the student information using useState.
- Displays student cards inside a ScrollView.
- Handles name searching using TextInput.
- Handles the flag status of each student.

React Native Core Components

- View
- Text
- Image
- ScrollView
- TextInput
- Pressable

How to Run

Install Node.js.
Open the project folder.

Install this:

   npm install

Then Start Expo:

   npx expo start

Open the application using Expo Go
   or an emulator.
